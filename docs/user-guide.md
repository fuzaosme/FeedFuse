# 使用指南

这份文档面向已经运行 FeedFuse 的使用者，帮助你完成首次登录、账号管理和日常阅读配置。

如果还没有启动服务，请先看 [部署指南](./deploy.md)。

## 1. 首次登录

打开部署后的访问地址，进入登录页：

```text
http://127.0.0.1:9559/login
```

全新数据库首次登录使用：

- 用户名：`admin`
- 密码：`.env` 里的 `AUTH_INITIAL_PASSWORD`

首次登录成功后，密码哈希会写入数据库。之后使用应用内保存的账号密码登录；修改 `.env` 中的 `AUTH_INITIAL_PASSWORD` 不会重置已有密码。

## 2. 修改当前账号

登录后打开：

```text
设置中心 -> 账号与安全 -> 当前账号 -> 编辑
```

你可以在这里修改：

- 用户名
- 新密码

只修改用户名不会让当前会话失效。修改密码后，系统会刷新当前会话。

## 3. 管理用户

只有 `管理员` 可以看到 `用户管理`。

管理员可以：

- 新增用户
- 修改非初始用户的用户名
- 调整用户角色为 `管理员` 或 `成员`
- 启用或禁用用户

只有 `初始用户` 可以删除其他用户。初始用户固定是系统创建的第一个用户，即首次登录时的 `admin` 账号。初始用户可以改名，但仍保留初始用户权限。

删除用户会同时删除该用户拥有的数据，包括订阅源、分类、Fever 服务、AI 解读任务和系统日志关联数据。这个操作无法恢复。

## 4. 理解角色

FeedFuse 当前有两种角色：

- `管理员`：可以进入用户管理，创建、编辑、启用或禁用用户
- `成员`：只能管理自己的订阅、设置和账号资料

所有用户都可以修改自己的用户名和密码。

## 5. 数据隔离

同一个 FeedFuse 实例可以给多个用户使用。不同用户之间默认隔离：

- RSS 源和分类
- 文章阅读状态
- Fever 服务和同步状态
- AI 配置、翻译配置和 UI 设置
- AI 解读、摘要、翻译和全文抓取任务

不同用户可以添加相同的 RSS 地址或 Fever 服务账号。它们会作为各自账号下的独立数据保存。

## 6. 添加 RSS 源

在主界面点击添加订阅源，填写 RSS 地址并选择分类。

如果还不知道订阅什么，可以点击左上角 FeedFuse 右侧的 `+ -> RSS 列表`。列表提供按分类、语言和关键词筛选的中英文来源；点击“添加”会自动填入订阅地址，验证成功后即可确认名称与分类并保存。已有订阅会显示为“已添加”。列表底部还有公开 RSS 目录和中文博客清单，可用于继续寻找来源。

如果需要批量迁移，可以使用：

```text
设置中心 -> RSS -> OPML 导入
```

导出的 OPML 只包含当前登录用户自己的订阅源。

订阅源更新失败时，将鼠标悬停在该源上即可查看错误详情。移入提示浮层后，可以选择并复制错误文案。涉及 fake-ip 或局域网访问的错误，请管理员按 [部署指南](./deploy.md#2-编辑-env) 检查 RSS 网络配置，再重新刷新。

添加或刷新订阅时，如果源站返回安全检测页，系统会尝试一次符合条件的 `www` / 裸域变体，只有返回有效 RSS/Atom 才视为恢复成功。仍受阻时会明确提示“源站返回了安全验证页面”，请稍后重试或使用源站提供的其他订阅地址；这类提示不表示订阅格式错误。

## 7. 配置 Fever 服务

如果你使用 FreshRSS、Tiny Tiny RSS 等兼容 Fever API 的服务，打开：

```text
设置中心 -> Fever 账号
```

你可以添加 Fever 服务、手动同步、启用或停用服务，并配置自动同步间隔。

Fever 托管源由远端服务负责管理。FeedFuse 会在本地展示这些源和文章，但不建议从普通 RSS 源编辑入口修改 Fever 托管源。

## 8. 配置 AI

如果只阅读 RSS，可以先跳过 AI 配置。

需要摘要、翻译或 `AI解读` 时，打开：

```text
设置中心 -> AI
```

1. 填写服务商提供的 `AI 模型`、`API 地址` 和 `API 密钥`。模型名需与服务商支持的名称一致，API 地址通常带 `/v1`。
2. 翻译默认选择 `复用主配置`。需要使用另一套服务时，切换到 `单独配置`，填写 `翻译模型`、`翻译 API 地址` 和 `翻译 API 密钥`。
3. 等待右上角显示 `已保存`，再打开文章尝试摘要或翻译。

配置按当前用户保存。摘要、翻译和 `AI解读` 依赖后台 Worker；任务一直等待时，请管理员按 [部署排查步骤](./deploy.md#常见问题与维护) 检查运行状态。

## 9. 退出登录

打开：

```text
设置中心 -> 账号与安全 -> 退出登录
```

退出后会结束当前会话并返回登录页。

## 10. 英语学习与词典

在阅读页顶部工具栏打开 `英语学习模式` 后，选中英文单词或句子即可查看释义或 AI 讲解，并可把单词加入生词本。

标题和正文里的链接文字也支持拖选、双击选词；普通单击仍打开原链接。

### 10.1 内置词库

应用自带约 2.9 万条核心英汉词条（考试大纲词汇与高频词），无需下载即可查词，常见单词不依赖网络。

### 10.2 下载更多词典

词典属于实例级配置，入口在设置中心，与阅读时的英语学习功能分开：

```text
设置中心 -> 词典
```

1. `ECDICT 完整版`：76.9 万条，含生僻词、专有名词和词形变化。下载约 63 MB，导入后占用数据库约 120 MB。
2. 下载在服务端完成，界面显示下载与导入进度；完成后自动启用，命中优先级高于内置词库。
3. 可以随时用开关停用某个词典，或点 `删除` 释放数据库空间。同一实例内所有账号共用一份词典。
4. 只有管理员可以安装、启停或删除词典；普通成员打开该页面只能查看当前已启用的词典。

### 10.3 从链接导入

`从链接导入` 支持两类来源：

- 应用自身的 JSON 结构：`{ "word": { "meanings": ["释义"], "phonetic": "" } }`
- ECDICT 格式的 CSV

链接必须是 `http(s)`，且默认不能指向内网地址；如需从内网导入，请先按 [部署指南](./deploy.md) 调整 `RSS_NETWORK_MODE`。请自行确认来源的授权与内容准确性。

### 10.4 语境讲解与详细解释

AI 讲解会带上选区所在的整段原文作为语境，因此同一句话在不同段落里的解释会不一样。

- `AI 句子讲解`：选中 4 个英文词以上时触发，按「语境定位 → 自然译文 → 逐句拆解 → 重点表达」讲解。提示词可在 `设置中心 -> AI` 的 `英语学习提示词` 中自定义，留空使用内置模板。
- `详细解释`：单词卡片上 `加入生词本` 旁边的图标按钮。词典释义读不懂时点它，会用一套独立的专用提示词解释该词在此处的确切含义、搭配、语境线索和迁移例句。该提示词固定内置、不可自定义，设置中心没有对应入口。
- 两种讲解使用不同的提示词，互不覆盖；缺少 AI 配置时会提示跳转设置。

### 10.5 数据来源与许可

内置词库与 `ECDICT 完整版` 均来自 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT License，Copyright (c) 2025 Linwei）。词典只下载到你自己的实例，不会上传任何数据。
